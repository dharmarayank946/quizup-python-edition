# QuizUp Python Edition - Requirements
# ====================================
# This application is built using Python's standard library:
# - tkinter (Desktop Graphical User Interface)
# - json (Data persistence)
# - os, shutil, tempfile (File and directory handling)
# - random (Question selection and option shuffling)
# - datetime (Timestamps and duration tracking)
# - unittest (Automated test suite)
#
# No external third-party dependencies are required.
# Minimum Python Version: Python 3.8+ with Tkinter support (included with standard Python installers).
